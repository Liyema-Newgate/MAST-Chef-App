Part two features are: 
    Dynamic Menu List: Starts empty (no hardcoded data). Chef adds items via a modal form.
    Predefined Courses: Dropdown (Picker) limits to Starters, Mains, Desserts.
    Display: Home screen shows total count and a scrollable list of items with all required details.
    No Permanent Storage: Uses local state (useState). Data resets on app reload.
    Validation: Basic checks for required fields and valid price.
    UI: Clean, mobile-friendly. 
App successfully runs on mobile emulators. 

Part 3 Features final: 
Chefs can manage the menu dynamically on a separate screen by adding new dishes or removing existing ones. The app features a dark-themed interface (grey, black, white) for a modern look and integrates fully interactive state management so changes appear in real time.
Key Features:
Browse menu items with category filters.
Add/remove dishes from a basket.
Proceed to a checkout simulation.
Chef panel for managing menu items dynamically
React Native / Expo Snack
